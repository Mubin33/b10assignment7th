# Some information about this project

1. The name of this project is "Make Cricket"
- The project live link : [Make Cricket](https://cricketmubinassignment.surge.sh/) 

2. Short description about this project 
- This project will work towards the development of cricket. Although cricket is very popular worldwide, I believe this project will play a unique role in providing accurate understanding and better presentation of cricket, especially in rural areas. Through this, people in villages will be able to learn more about the rules, playing techniques, and training in cricket. The project may have some limitations, but I will continually improve it based on user feedback. It is hoped that the project will inspire a love for cricket among the rural youth and contribute to discovering future talent.
